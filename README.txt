ILLUSTRATION PORTFOLIO — QUICK START

FILES
- index.html      Homepage
- projects.html   Project gallery and filterable project details
- about.html      About, skills, experience, and contact form
- styles.css      Shared styling for all three pages
- script.js       Mobile navigation, project filters, contact form, and current year

HOW TO VIEW
1. Keep all five files in the same folder.
2. Open index.html in a browser. The navigation links connect all three pages.
3. For local development, you can also run: python -m http.server 8000
   Then visit http://localhost:8000

CUSTOMIZE BEFORE SENDING TO EMPLOYERS
1. Replace [YOUR NAME], [Your Name], school, degree, dates, and all bracketed placeholder text.
2. Replace the decorative CSS artwork on the homepage and project page with your own project images.
   Search for the .project-art and .detail-art elements in the HTML/CSS.
3. Update hello@example.com in BOTH about.html and script.js to your real email address.
   The contact form opens the visitor's email application; it does not send messages through a server.
4. Replace [RESUME-PDF-LINK] with your résumé PDF URL or file path.
5. Replace [LINKEDIN-URL] with your profile URL.
6. Update the skills and project tags so they accurately describe your experience.

NOTES
- The site is responsive and includes a mobile navigation menu.
- The Projects page has working category filters.
- The contact form validates required fields and prepares an email using mailto.
- Google Fonts are loaded online; system sans-serif fallbacks are included.
